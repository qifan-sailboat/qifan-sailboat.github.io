Kick Bad Guys Out! Conditionally Activated Anomaly Detection in Federated Learning with Zero-Knowledge Proof Verification

Shanshan Han, Wenxuan Wu, Baturalp Buyukates, Weizhao Jin, Qifan Zhang, Yuhang Yao, Salman Avestimehr

Workshop on Attack Provenance, Reasoning, and Investigation for Security in the Monitored Environment (PRISM), co-located with NDSS 2026

PDF DOI Cite “

Overview

CustodianFL protects federated learning from malicious client updates using a two-stage detection process. It first screens behavior across training rounds, then examines flagged clients with a statistical check and removes models identified as malicious. Zero-knowledge proofs let clients verify that the server executed the detection process correctly. The approach activates its more intensive checks only when suspicious behavior appears, aiming to preserve model training in benign settings.
